# ESP32-DevKit-V1-LCD-16x2-NTP-Clock
The **ESP32-DevKit-V1-LCD-16x2-NTP-Clock** is an NTP-based synchronization project that demonstrates how Network Time Protocol (NTP) can provide accurate time information for display on a 16×2 LCD using an ESP32 DevKit V1.

***Requirements***
**i)** LCD 16x2 Display
**ii)** ESP32 that has WIFI, It is still recommended to use Online to check the code validation.

***Library***
**i)** LiquidCrystal_I2C.h
**ii)** WiFi.h
**iii)** Wire.h
**iv)** time.h


***Recommendation***
**i)** For ESP32 DevKit V1, GPIO 21 OR D21 = SDA 
**ii)** For ESP32 DevKit V1, GPIO 22 OR D22 = SCL

***IDE***
**i**) ARDUINO IDE WAS USED .
